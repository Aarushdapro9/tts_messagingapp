## Game mechanic references

The Knockout, Crazy 8 Ball, Word Hunt, and Filler repositories named in the
product request were reviewed only as gameplay references. Their repositories
did not expose a reusable licence for their source or artwork at the time of
integration. This project therefore contains clean-room browser/server
implementations and does not include their code, assets, branding, or
dependencies.

- https://github.com/mchen1820/Knockout
- https://github.com/snigdhasaha7/crazy8ball
- https://github.com/Marlo-Ong/word-hunt-recreated
- https://github.com/adrian-thumbtack/filler-game

## 2D-mini-golf browser multiplayer port

The Mini Golf game is a browser multiplayer port of [xFrednet/2D-mini-golf](https://github.com/xFrednet/2D-mini-golf). It retains the reference project's five level object layouts, hold-and-release control model, stepped collision approach, and sine/circular moving obstacle patterns. The JavaScript networking, authoritative turn system, match persistence, responsive SVG renderer, player scoring, and UI integration are additions for this app.
